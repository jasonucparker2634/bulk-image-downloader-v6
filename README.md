## Overview

Bulk Image Downloader is built for image-gathering tasks that extend beyond one source page. The crawler can follow connected content recursively, download assets concurrently, and arrange the resulting files into an organized structure for easier handling of larger collections.

The tool also supports repeatable batch processes, scheduled jobs, and longer-running sessions that may be resumed later. A browser-based web UI and dashboard provide controls for changing settings, observing active work, and checking download progress.

## Using the Downloader

A normal workflow begins with a source page or collection, expands through related content when recursive crawling is enabled, and uses the dashboard to follow the job.

1. Launch the web UI.
2. Enter a source page or collection URL.
3. Configure crawl depth, proxy information, and scheduling preferences as required.
4. Begin the download job and monitor it from the dashboard.
5. Resume or run the session again when previous work needs to continue.

When managing multiple batches, grouping sources by project helps keep the generated output easy to browse.

## Frequently Asked Questions

**How can I check whether a download job is active?**  
Open the live dashboard to view current progress, active tasks, and session status.

**Can an interrupted job be continued?**  
Yes. Resume support is available for sessions that were interrupted.

**Are scheduled and repeat downloads supported?**  
Yes, the workflow includes scheduled downloads for recurring runs.

**How are crawl depth and proxy options configured?**  
Adjust them in the web UI configuration controls, or modify the local settings when your installation uses configuration files.

**What can I check when the downloaded output is incomplete?**  
Verify the source URL, crawl depth, proxy setup, and session state. After checking those values, rerun the job if necessary.
